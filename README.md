# E-commerce Database Management & Sales Analysis

## Project Overview
This is a self-directed SQL project developed using MySQL to practise relational database management and business data analysis.

## Database Tables
- Customers
- Products
- Orders
- Order_Items

## SQL Concepts Used
- Data Definition Language (DDL)
- Data Manipulation Language (DML)
- Joins and Subqueries
- Aggregate Functions
- GROUP BY and HAVING
- Common Table Expressions (CTEs)
- Window Functions
- Date and String Functions
- NULL and Duplicate Checks

## Business Analysis
- Monthly revenue analysis
- Top customers by spending
- Product and category performance
- Customer purchase analysis
- Profit and profit margin analysis

## Tools
MySQL | MySQL Workbench
